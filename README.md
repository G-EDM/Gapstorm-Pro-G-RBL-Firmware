# Alpha Release
This firmware is made for the new G-EDM Gapstorm and Gapstorm Pro boards.
It is currently not considered finished, but many bugs have been fixed, and the code is much easier for users to access. I decided to provide an early release for people who have been waiting already way too long and want to have some fun with their hardware.
</br>
There has been a lot of tinkering recently, and the time available to work on the firmware has been limited. Please keep in mind that this release is not considered ready yet. I just now had time to get back to the software side of the project and created the very first sinker cut, which worked pretty well out of the box.
